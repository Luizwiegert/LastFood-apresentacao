# LastFood

**Ainda dá tempo.**

O LastFood conecta a gestão de desperdício em estabelecimentos a um aplicativo de ofertas de alimentos com desconto e retirada presencial.

## Duas experiências conectadas

| Sistema para estabelecimentos | Aplicativo para consumidores |
| --- | --- |
| Cadastro de produtos, custos e preços | Busca por ofertas de comércios próximos |
| Registro de produção, vendas e sobras | Reserva para retirada no balcão |
| Sugestões de produção com base no histórico | Código de retirada e histórico de pedidos |
| Publicação de ofertas e confirmação de retiradas | Dados da conta e preferências |

Restaurantes, padarias e outros comércios podem acompanhar suas sobras e oferecer o excedente do dia em uma janela de retirada.

## Como funciona

1. O estabelecimento registra o que produziu e o que sobrou.
2. Confere os alimentos disponíveis, o preço e o horário de retirada.
3. Publica a oferta.
4. O cliente reserva pelo aplicativo e retira o pedido no balcão.
